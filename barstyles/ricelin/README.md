# Ricelin

Ricelin is a customizable pill-style bar for Ryoku with dynamic theming,
workspace and media controls, system surfaces, tray integration, and smooth
shape transitions.

The Ryostore port delegates host configuration to Ryoku while retaining
Ricelin's bar-local appearance and interaction settings. Detailed source,
licensing, and integration history is recorded in `PROVENANCE.txt`.

The runtime entry is `qml/Scene.qml`.
