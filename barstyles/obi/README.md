# Obi

Obi is a compact floating top bar for Ryoku. Kanji workspaces sit in the centre,
with active-window and media controls on the left and status, tray, and weather
controls on the right.

Ryoku Hub edits its visible modules through the built-in Obi editor. The style
uses Ryoku's shared shell services and runs one scene per display.

The runtime entry is `qml/Scene.qml`.
